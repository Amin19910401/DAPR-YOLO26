# Split Manifests

This directory contains the exact file lists (manifests) for the train,
validation, and test partitions used in this work.

## Files

- train.txt: 23,001 training image filenames
- val.txt: 7,682 validation image filenames
- test_original.txt: 2,551 original (non-augmented) test image filenames

## How to regenerate the manifests

Run the following command from the repository root:

    python scripts/generate_splits.py

The script requires the EAGLE dataset (HBB-converted) to be organized as:

    Dataset/
        images/
            train/
            val/
            test/
        labels/
            train/
            val/
            test/
        data.yaml

## Filtering logic

The test manifest is generated by a deterministic filter that retains only
filenames containing the token _original_:

    python scripts/filter_original_test.py

This ensures that each source image contributes exactly once to the
reported metrics, and that no transformed views (flips or rotations) of
the same source image are included in the evaluation.
